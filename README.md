# **关于“微备份”应用下架及服务调整的公告**


**尊敬的用户：**

​近日，我们收到腾讯公司委托律师事务所发出的律师函。律师函对“微备份”应用及相关安装包的上传、发布、传播、下载、安装和使用等事项提出异议，并要求我们进行整改。 我们高度重视此次事项。为妥善落实整改要求，同时保障用户有合理时间恢复、迁移已有数据，现决定对“微备份”应用及相关服务作出如下调整：

**一、停止应用分发及下载**

​“微备份”此前仅通过fnOS应用中心和GitHub两个渠道发布。自【2026年10月31日】起，我们启动上述两个渠道中“微备份”应用及相关安装包的下架工作，停止提供相关应用的下载、安装。

**二、设置用户数据恢复过渡期**

​考虑到部分用户需要时间恢复、迁移此前保存的数据，我们将设置数据恢复过渡期。过渡期为【2026年11月1日0时】至【2027年2月28日24时】。

​过渡期内，我们仅为已安装应用且已有服务器备份数据的用户，保留已有数据查询、恢复及迁移所必需的服务器功能，不再开放新用户注册，不再接受新的数据备份，也不再提供应用下载、安装。 

​除上述必要的数据恢复及迁移功能外，其他相关服务将同步停止。请需要恢复或迁移数据的用户在上述期限届满前完成相关操作。过渡期届满后，我们将停止相关服务器服务，届时尚未恢复或迁移的服务器数据可能无法再行访问或恢复。 

**三、后续安排**

​整改期间，我们将停止“微备份”相关功能的开发、发布及推广。由此给您带来的不便，我们深表歉意。感谢您对本次调整的理解与配合。
